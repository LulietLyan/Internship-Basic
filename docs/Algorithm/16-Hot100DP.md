# 动态规划

## [爬楼梯](https://leetcode.cn/problems/climbing-stairs/?envType=study-plan-v2&envId=top-100-liked)

**题目描述** ：每次可以爬 `1` 或 `2` 级台阶，求到达第 `n` 级台阶共有多少种方法。

**算法解析** ：到达第 `i` 级只能从 `i - 1` 或 `i - 2` 转移而来，因此 `dp[i] = dp[i - 1] + dp[i - 2]`。这就是斐波那契模型，可以用两个变量滚动优化空间。

```C++
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    int climbStairs(int n) {
        if (n <= 2) return n;
        int a = 1, b = 2;
        for (int i = 3; i <= n; i++) {
            int c = a + b;
            a = b;
            b = c;
        }
        return b;
    }
};

int main() {
    int n;
    cin >> n;
    Solution solution;
    cout << solution.climbStairs(n) << endl;
    return 0;
}
```

## [杨辉三角](https://leetcode.cn/problems/pascals-triangle/?envType=study-plan-v2&envId=top-100-liked)

**题目描述** ：给定行数 `numRows`，生成杨辉三角的前 `numRows` 行。

**算法解析** ：每一行首尾都是 `1`，中间位置由上一行相邻两个数相加得到，即 `ans[i][j] = ans[i - 1][j - 1] + ans[i - 1][j]`。

```C++
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    vector<vector<int>> generate(int numRows) {
        vector<vector<int>> ans(numRows);
        for (int i = 0; i < numRows; i++) {
            ans[i].assign(i + 1, 1);
            for (int j = 1; j < i; j++) {
                ans[i][j] = ans[i - 1][j - 1] + ans[i - 1][j];
            }
        }
        return ans;
    }
};

int main() {
    int numRows;
    cin >> numRows;
    Solution solution;
    vector<vector<int>> ans = solution.generate(numRows);
    for (auto& row : ans) {
        for (int i = 0; i < row.size(); i++) {
            if (i) cout << " ";
            cout << row[i];
        }
        cout << endl;
    }
    return 0;
}
```

## [打家劫舍](https://leetcode.cn/problems/house-robber/?envType=study-plan-v2&envId=top-100-liked)

**题目描述** ：给定每间房的金额，不能偷相邻房屋，求能偷到的最大金额。

**算法解析** ：对于第 `i` 间房，有偷和不偷两种选择：偷则收益为 `dp[i - 2] + nums[i]`，不偷则收益为 `dp[i - 1]`。取最大值即可，空间可以滚动压缩为两个变量。

```C++
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    int rob(vector<int>& nums) {
        int prev2 = 0, prev1 = 0;
        for (int x : nums) {
            int cur = max(prev1, prev2 + x);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
};

int main() {
    int n;
    cin >> n;
    vector<int> nums(n);
    for (int i = 0; i < n; i++) cin >> nums[i];

    Solution solution;
    cout << solution.rob(nums) << endl;
    return 0;
}
```

## [完全平方数](https://leetcode.cn/problems/perfect-squares/?envType=study-plan-v2&envId=top-100-liked)

**题目描述** ：给定正整数 `n`，返回和为 `n` 的完全平方数的最少数量。

**算法解析** ：这是完全背包的最小数量问题。令 `dp[i]` 表示凑出 `i` 的最少平方数个数，枚举所有 `j * j <= i`，转移为 `dp[i] = min(dp[i], dp[i - j * j] + 1)`。

```C++
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    int numSquares(int n) {
        vector<int> dp(n + 1, INT_MAX / 2);
        dp[0] = 0;
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j * j <= i; j++) {
                dp[i] = min(dp[i], dp[i - j * j] + 1);
            }
        }
        return dp[n];
    }
};

int main() {
    int n;
    cin >> n;
    Solution solution;
    cout << solution.numSquares(n) << endl;
    return 0;
}
```

## [零钱兑换](https://leetcode.cn/problems/coin-change/?envType=study-plan-v2&envId=top-100-liked)

**题目描述** ：给定硬币面额数组和总金额 `amount`，每种硬币可无限使用，求凑出总金额所需的最少硬币数；无法凑出则返回 `-1`。

**算法解析** ：完全背包最小值模型。`dp[x]` 表示凑出金额 `x` 的最少硬币数，初始化为无穷大，`dp[0] = 0`。对每个金额枚举硬币，若能选择该硬币，则用 `dp[x - coin] + 1` 更新答案。

```C++
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {
        const int INF = amount + 1;
        vector<int> dp(amount + 1, INF);
        dp[0] = 0;
        for (int x = 1; x <= amount; x++) {
            for (int coin : coins) {
                if (x >= coin) {
                    dp[x] = min(dp[x], dp[x - coin] + 1);
                }
            }
        }
        return dp[amount] == INF ? -1 : dp[amount];
    }
};

int main() {
    int n, amount;
    cin >> n >> amount;
    vector<int> coins(n);
    for (int i = 0; i < n; i++) cin >> coins[i];

    Solution solution;
    cout << solution.coinChange(coins, amount) << endl;
    return 0;
}
```

## [单词拆分](https://leetcode.cn/problems/word-break/?envType=study-plan-v2&envId=top-100-liked)

**题目描述** ：给定字符串 `s` 和单词字典，判断 `s` 是否可以由字典中的单词拼接而成。

**算法解析** ：令 `dp[i]` 表示前 `i` 个字符能否被拆分。若存在 `j < i`，满足 `dp[j]` 为真且 `s[j..i-1]` 在字典中，则 `dp[i] = true`。最终返回 `dp[n]`。

```C++
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> words(wordDict.begin(), wordDict.end());
        int n = s.size();
        vector<bool> dp(n + 1, false);
        dp[0] = true;

        for (int i = 1; i <= n; i++) {
            for (int j = 0; j < i; j++) {
                if (dp[j] && words.count(s.substr(j, i - j))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[n];
    }
};

int main() {
    string s;
    int m;
    cin >> s >> m;
    vector<string> wordDict(m);
    for (int i = 0; i < m; i++) cin >> wordDict[i];

    Solution solution;
    cout << (solution.wordBreak(s, wordDict) ? "true" : "false") << endl;
    return 0;
}
```

## [最长递增子序列](https://leetcode.cn/problems/longest-increasing-subsequence/?envType=study-plan-v2&envId=top-100-liked)

**题目描述** ：给定整数数组，求最长严格递增子序列的长度。

**算法解析** ：维护数组 `tails`，其中 `tails[len]` 表示长度为 `len + 1` 的递增子序列的最小结尾。遍历每个数，用二分找到第一个大于等于它的位置并替换。`tails` 越小，后续扩展空间越大。

```C++
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        vector<int> tails;
        for (int x : nums) {
            auto it = lower_bound(tails.begin(), tails.end(), x);
            if (it == tails.end()) tails.push_back(x);
            else *it = x;
        }
        return tails.size();
    }
};

int main() {
    int n;
    cin >> n;
    vector<int> nums(n);
    for (int i = 0; i < n; i++) cin >> nums[i];

    Solution solution;
    cout << solution.lengthOfLIS(nums) << endl;
    return 0;
}
```

## [乘积最大子数组](https://leetcode.cn/problems/maximum-product-subarray/?envType=study-plan-v2&envId=top-100-liked)

**题目描述** ：给定整数数组，求乘积最大的非空连续子数组的乘积。

**算法解析** ：由于负数会让最大值和最小值互换，需要同时维护以当前位置结尾的最大乘积 `maxProd` 和最小乘积 `minProd`。遇到负数先交换二者，再分别用当前数更新。

```C++
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int maxProd = nums[0];
        int minProd = nums[0];
        int ans = nums[0];

        for (int i = 1; i < nums.size(); i++) {
            if (nums[i] < 0) swap(maxProd, minProd);
            maxProd = max(nums[i], maxProd * nums[i]);
            minProd = min(nums[i], minProd * nums[i]);
            ans = max(ans, maxProd);
        }
        return ans;
    }
};

int main() {
    int n;
    cin >> n;
    vector<int> nums(n);
    for (int i = 0; i < n; i++) cin >> nums[i];

    Solution solution;
    cout << solution.maxProduct(nums) << endl;
    return 0;
}
```

## [分割等和子集](https://leetcode.cn/problems/partition-equal-subset-sum/?envType=study-plan-v2&envId=top-100-liked)

**题目描述** ：给定只包含正整数的数组，判断是否能分成两个元素和相等的子集。

**算法解析** ：总和为奇数时一定不能分割。问题转化为是否能从数组中选出若干元素，使其和为 `sum / 2`。使用 0-1 背包，`dp[j]` 表示容量 `j` 是否可达，遍历每个数时倒序更新。

```C++
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    bool canPartition(vector<int>& nums) {
        int sum = accumulate(nums.begin(), nums.end(), 0);
        if (sum % 2) return false;
        int target = sum / 2;
        vector<bool> dp(target + 1, false);
        dp[0] = true;

        for (int x : nums) {
            for (int j = target; j >= x; j--) {
                dp[j] = dp[j] || dp[j - x];
            }
        }
        return dp[target];
    }
};

int main() {
    int n;
    cin >> n;
    vector<int> nums(n);
    for (int i = 0; i < n; i++) cin >> nums[i];

    Solution solution;
    cout << (solution.canPartition(nums) ? "true" : "false") << endl;
    return 0;
}
```

## [最长有效括号](https://leetcode.cn/problems/longest-valid-parentheses/?envType=study-plan-v2&envId=top-100-liked)

**题目描述** ：给定只包含 `(` 和 `)` 的字符串，求最长有效括号子串的长度。

**算法解析** ：用栈保存可能作为边界的下标，先压入 `-1` 作为哨兵。遇到 `(` 入栈；遇到 `)` 先弹出一个左括号位置，若栈空则把当前下标作为新的无效边界，否则用 `i - st.top()` 更新最长长度。

```C++
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    int longestValidParentheses(string s) {
        stack<int> st;
        st.push(-1);
        int ans = 0;

        for (int i = 0; i < s.size(); i++) {
            if (s[i] == '(') {
                st.push(i);
            } else {
                st.pop();
                if (st.empty()) {
                    st.push(i);
                } else {
                    ans = max(ans, i - st.top());
                }
            }
        }
        return ans;
    }
};

int main() {
    string s;
    cin >> s;
    Solution solution;
    cout << solution.longestValidParentheses(s) << endl;
    return 0;
}
```
